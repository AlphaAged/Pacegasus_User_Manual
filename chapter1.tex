\section{ความเป็นมาและความสำคัญของปัญหา}
การวิ่งเป็นกิจกรรมทางกายที่เข้าถึงง่าย ไม่ต้องใช้อุปกรณ์ซับซ้อน และมีประสิทธิภาพในการป้องกันโรคไม่ติดต่อเรื้อรัง อย่างไรก็ตาม ผู้ที่เริ่มวิ่งจำนวนมากมักหยุดออกกำลังกายในระยะเวลาอันสั้น เนื่องจากขาดแรงจูงใจที่เหมาะสมและระบบสนับสนุนอย่างต่อเนื่อง ปัญหาหลักประกอบด้วยการขาดเป้าหมายที่ชัดเจน การไม่มีระบบติดตามความก้าวหน้า และการขาดปฏิสัมพันธ์เชิงบวกจากสังคมรอบข้าง
 ผู้พัฒนาจึงเล็งเห็นความสำคัญของการสร้างแรงจูงใจในการวิ่ง และมีแนวคิดพัฒนาแอปพลิเคชัน Pacegasus เพื่อช่วยให้ผู้ใช้งานกำหนดเป้าหมาย วางแผนการวิ่ง ติดตามผลการออกกำลังกาย และเข้าร่วมกิจกรรมกับผู้อื่น โดยมุ่งหวังให้ผู้ใช้งานมีแรงจูงใจและสามารถวิ่งได้อย่างต่อเนื่อง

\section{เครื่องมือที่ใช้ในการพัฒนา}

    \item RAM : 16 GB
\end{enumerate}

    \item ซอฟต์แวร์

\section{ขอบเขตและข้อจำกัดของการวิจัย}
\subsection{ขอบเขตของผู้ใช้งานทั่วไป}
\begin{itemize}[label={-}]
    \item สามารถสมัครสมาชิก เข้าสู่ระบบ และจัดการข้อมูลส่วนตัวได้
    \item สามารถบันทึกข้อมูลสุขภาพประจำวันและประเมินความเหนื่อยหลังการวิ่งได้
    \item สามารถเลือกแผนการฝึก จัดตารางการวิ่ง และดูคำแนะนำในการปรับแผนเฉพาะบุคคลได้
    \item สามารถติดตามและบันทึกการวิ่งด้วย GPS รวมถึงดูประวัติและสถิติการวิ่งได้
    \item สามารถเข้าร่วมภารกิจ สะสมคะแนนและเหรียญ รวมถึงแลกไอเทมเพื่อตกแต่งอวตาร์ได้
    \item สามารถจัดการรายชื่อเพื่อน ค้นหา เข้าร่วม และออกจากคลับได้
    \item สามารถสร้างคลับและดูตารางจัดอันดับของเพื่อนหรือสมาชิกในคลับได้
\end{itemize}

\subsection{ขอบเขตของหัวหน้าคลับ}
\begin{itemize}[label={-}]
    \item สามารถใช้งานฟังก์ชันทั้งหมดของผู้ใช้งานทั่วไปได้
    \item สามารถแก้ไขข้อมูลของคลับที่ตนเองเป็นหัวหน้าได้
    \item สามารถดูรายชื่อสมาชิกและอนุมัติหรือปฏิเสธคำขอเข้าร่วมคลับได้
    \item สามารถนำสมาชิกออกจากคลับที่ตนเองเป็นหัวหน้าได้
    \item สามารถโอนสิทธิ์หัวหน้าคลับให้สมาชิกคนอื่นได้
    \item สามารถยุบคลับที่ตนเองเป็นหัวหน้าได้
\end{itemize}

\subsection{ขอบเขตและข้อจำกัดของของระบบ}
\begin{itemize}[label={-}]
    \item พัฒนาในรูปแบบแอปพลิเคชันมือถือเท่านั้น
    \item รองรับเฉพาะระบบปฏิบัติการ Android
    \item จัดการข้อมูลโดยใช้ฐานข้อมูล PostgreSQL
    \item ไม่มีระบบการชำระเงิน
    \item ความแม่นยำของ GPS ขึ้นอยู่กับอุปกรณ์และสภาพแวดล้อมของผุ้ใช้
\end{itemize}

\section{ประโยชน์ที่คาดว่าจะได้รับ}
\subsection{ผู้ใช้งานสามารถวางแผนและจัดตารางการวิ่งได้อย่างเหมาะสมกับเป้าหมายและเวลาว่างของตนเอง}

\subsection{ผู้ใช้งานได้รับคำแนะนำในการปรับแผนการฝึกตามข้อมูลสุขภาพ ความเหนื่อย และผลการวิ่งของตนเอง}

\subsection{ผู้ใช้งานสามารถติดตามประวัติ สถิติ และความก้าวหน้าในการวิ่ง เพื่อใช้ประกอบการพัฒนาการฝึกของตนเอง}

\subsection{ผู้ใช้งานมีแรงจูงใจในการวิ่งอย่างต่อเนื่องผ่านภารกิจ การสะสมคะแนน เหรียญ และการตกแต่งอวตาร์}

\subsection{ผู้ใช้งานสามารถสร้างความสัมพันธ์และแลกเปลี่ยนประสบการณ์กับเพื่อนหรือสมาชิกในคลับ เพื่อส่งเสริมการออกกำลังกายร่วมกัน}

\subsection{หัวหน้าคลับสามารถจัดการข้อมูลและสมาชิกของคลับผ่านแอปพลิเคชันได้อย่างสะดวก}
