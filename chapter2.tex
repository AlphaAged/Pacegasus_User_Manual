    \item อ่านองค์ประกอบการซ้อมแต่ละประเภท รวมถึงปริมาณการฝึกและจำนวนวันต่อสัปดาห์

\subsection{การลงทะเบียนและจัดตารางซ้อมรายสัปดาห์}
\begin{enumerate}[label=\arabic*)]
    \item ที่หน้าลงตารางซ้อม ตรวจสอบชื่อโปรแกรมและระดับที่เลือกไว้
    \item เลือกระยะเวลาฝึกจากตัวเลือกที่แสดง เช่น 6 ถึง 10 สัปดาห์ในภาพตัวอย่าง
    \item ในส่วนจัดตารางรายสัปดาห์ เลือกประเภทการซ้อม เช่น Easy Run หรือ Long Run

    \item ตรวจสอบจำนวนครั้งที่เหลือของการซ้อมแต่ละประเภท และจัดตารางของสัปดาห์นั้นให้ครบ
    \item ตรวจสอบตารางก่อนบันทึก โดยขั้นตอนการลงตารางซ้อมของสัปดาห์ถัดไป
    อธิบายเพิ่มเติมในหัวข้อถัดไป
\end{enumerate}

\subsubsection{การลงตารางซ้อมของสัปดาห์ถัดไป}
หากต้องการลงตารางซ้อมของสัปดาห์ถัดไปหลังจากจัดตารางสัปดาห์แรกแล้ว
สามารถกลับเข้ามาจัดตารางเพิ่มเติมได้ดังนี้
\begin{enumerate}[label=\arabic*)]
    \item ที่หน้าหลัก เปิดเมนูด้านขวา แล้วกด ตารางซ้อม ตามกรอบในภาพ
    \item ตรวจสอบหมายเลขสัปดาห์ในหน้าลงตารางซ้อมให้ตรงกับสัปดาห์ที่ต้องการจัด
    เช่น สัปดาห์ที่ 2 ในภาพตัวอย่าง
    หากต้องการเปลี่ยนสัปดาห์ ให้ใช้ปุ่มลูกศรหรือปุ่ม ไปสัปดาห์ที่ ตามที่ระบบแสดง
    \item เลือกประเภทการซ้อม เช่น Easy Run หรือ Long Run
    จากนั้นแตะช่องวันจันทร์ถึงวันอาทิตย์ที่ต้องการลงตาราง
    โดยตรวจสอบจำนวนครั้งที่เหลือของแต่ละประเภทประกอบด้วย
    \item จัดตารางของสัปดาห์ที่เลือกให้ครบ แล้วกดปุ่ม บันทึกตารางสัปดาห์
    \item ตรวจสอบส่วนความคืบหน้าตารางฝึก ซึ่งแสดงจำนวนสัปดาห์ที่จัดครบแล้ว
    และทำขั้นตอนเดียวกันเมื่อต้องการจัดตารางของสัปดาห์อื่น

\subsection{การบันทึกสุขภาวะประจำวัน (Daily Wellness)}
หน้า Daily Wellness Check-in ใช้สำหรับบันทึกข้อมูลความพร้อมของผู้ใช้งานในแต่ละวัน
โดยมีขั้นตอนดังนี้
\begin{enumerate}[label=\arabic*)]
    \item เข้าสู่หน้า Daily Wellness Check-in และตรวจสอบวันที่ที่แสดงด้านบน
    \item เลื่อนแถบคุณภาพการนอนให้ตรงกับการนอนของตนเอง
    และระบุจำนวนชั่วโมงนอนด้วยแถบที่แสดงช่วง 1 ถึง 12 ชั่วโมง
    \item เลื่อนแถบความเมื่อยล้ากล้ามเนื้อและระดับพลังกล้ามเนื้อตามความรู้สึกของตนเอง
    \item ระบุระดับความเครียดและแรงจูงใจในการออกกำลังกาย
    \item ตรวจสอบข้อมูลทั้ง 6 รายการ แล้วกดปุ่ม บันทึก
\end{enumerate}

    \item เลือกระดับความหนักที่รู้สึกขณะออกกำลังกาย (RPE)
    โดยเลื่อนตัวเลือกจากระดับเบาสบายไปจนถึงหนักสุดให้ตรงกับการวิ่งครั้งนั้น
    \item เลือกระดับความเครียดจากผ่อนคลายไปจนถึงเครียดมาก
    และกรอกข้อมูลอารมณ์หลังวิ่งในส่วนที่ระบบแสดง
    \item เมื่อตรวจสอบและกรอกข้อมูลเรียบร้อยแล้ว กดปุ่ม ส่งข้อมูล

    \item กดไอคอนดินสอข้างชื่อคลับ หมายเลข 2 เพื่อแก้ไขชื่อคลับ
    \item กดไอคอนดินสอในส่วนคำขวัญคลับ หมายเลข 3 เพื่อแก้ไขข้อความของคลับ

\subsection{การจัดการบทบาทและสิทธิ์}
\begin{enumerate}[label=\arabic*)]
    \item กด จัดการคลับ แล้วเลือก บทบาทและสิทธิ์ หมายเลข 2
    ในภาพเมนูจัดการคลับ
    \item ในหน้าบทบาทและสิทธิ์ เลือกกำหนดสิทธิ์ของ รองหัวหน้าคลับ หรือ สมาชิก
    โดยหัวหน้าคลับมีทุกสิทธิ์เสมอตามข้อความที่ระบบแสดง
    \item กดสวิตช์ข้างสิทธิ์ที่ต้องการกำหนด ได้แก่ อนุมัติคำขอเข้าร่วม
    เชิญสมาชิก นำสมาชิกออก และแก้ไขข้อมูลคลับ
    สวิตช์สีม่วงแสดงว่าเปิดสิทธิ์ และสีเทาแสดงว่าปิดสิทธิ์
    \item หากต้องการเปลี่ยนบทบาทของสมาชิก ให้เลือก จัดการบทบาทสมาชิก
    หรือเปิดโปรไฟล์สมาชิกแล้วกด จัดการสมาชิก ตามหัวข้อถัดไป
\end{enumerate}

\subsection{การดูโปรไฟล์และจัดการสมาชิกคลับ}

    ตามหมายเลข 5 ในภาพที่ \ref{fig:club-owner-overview}
    \item ระบบแสดงโปรไฟล์ผู้เล่น ซึ่งประกอบด้วยชื่อ UID คลับ ระดับ

    \item หากต้องการเปลี่ยนบทบาท ให้กด จัดการสมาชิก หมายเลข 1
    ในภาพที่ \ref{fig:club-owner-member-management}

    \item เมื่อตรวจสอบหรือจัดการเรียบร้อยแล้ว กดเครื่องหมายกากบาทที่มุมขวาบน
