\subsection{การติดตั้ง Flutter SDK}
ขั้นตอนต่อไปนี้เป็นการติดตั้ง Flutter SDK บนระบบปฏิบัติการ Windows
โดยดาวน์โหลดไฟล์ SDK และเพิ่มตำแหน่งโฟลเดอร์ bin ลงใน Path
\begin{enumerate}[label=\arabic*)]
    \item เปิดเว็บไซต์ \url{https://docs.flutter.dev/install/manual}
    เลือกแพลตฟอร์ม Windows แล้วดาวน์โหลด Flutter SDK ในรูปแบบไฟล์ .zip
    จากส่วน Download the Flutter SDK bundle
    \item แตกไฟล์ .zip ไปยังโฟลเดอร์ที่ต้องการเก็บ SDK
    เช่น \verb|C:\flutter| แล้วตรวจสอบว่ามีโฟลเดอร์ bin อยู่ภายใน
    เลือกตำแหน่งที่ไม่มีช่องว่างและไม่ต้องใช้สิทธิ์ผู้ดูแลระบบในการเขียนไฟล์
\end{enumerate}

\subsubsection{การตั้งค่า Path ของ Flutter SDK}
\begin{enumerate}[label=\arabic*)]
    \item เปิดหน้าต่าง System Properties เลือกแท็บ Advanced
    แล้วกด Environment Variables
    \item ในส่วน System variables เลือก Path แล้วกด Edit
    เพื่อกำหนดตำแหน่งสำหรับผู้ใช้ทุกคนในเครื่อง
    ทั้งนี้ ภาพตัวอย่างแสดงการแก้ไข Path ในส่วน User variables
    ซึ่งใช้สำหรับบัญชีผู้ใช้ปัจจุบัน และสามารถเพิ่มตำแหน่ง Flutter ได้เช่นกัน
    ให้เลือกตั้งค่าในส่วนที่ต้องการใช้งานเพียงส่วนเดียว
    \item ตรวจสอบรายการเดิม หากยังไม่มีตำแหน่ง Flutter ให้กด New
    แล้วกรอกตำแหน่งโฟลเดอร์ bin ของ Flutter SDK เช่น \verb|C:\flutter\bin|
    โดยเปลี่ยนให้ตรงกับตำแหน่งที่แตกไฟล์ไว้จริง
    \item กด OK เพื่อบันทึก จากนั้นกด OK ในหน้าต่างที่เหลือเพื่อปิดการตั้งค่า
\end{enumerate}

\subsubsection{การตรวจสอบหลังติดตั้ง}
ปิดและเปิด Terminal รวมถึงโปรแกรมแก้ไขโค้ดใหม่เพื่อให้ใช้ค่า Path ที่บันทึกไว้
จากนั้นตรวจสอบด้วยคำสั่งต่อไปนี้
\begin{verbatim}
flutter --version
dart --version
flutter doctor
\end{verbatim}
ตรวจสอบหมายเลขรุ่นและผลจาก flutter doctor
แล้วติดตั้งเครื่องมือที่ยังขาดตามแพลตฟอร์มที่ต้องการพัฒนา

\subsection{การติดตั้ง Visual Studio Code}

\subsection{การติดตั้ง Node.js}
ขั้นตอนต่อไปนี้เป็นการติดตั้ง Node.js บนระบบปฏิบัติการ Windows
และตรวจสอบค่า Path เพื่อให้เรียกใช้งานจากหน้าต่างคำสั่งได้
\begin{enumerate}[label=\arabic*)]
    \item ดาวน์โหลดไฟล์ติดตั้งจาก \url{https://nodejs.org/en/download}
    โดยเลือกตัวติดตั้งสำหรับ Windows ให้ตรงกับสถาปัตยกรรมของเครื่อง
    \item เปิดไฟล์ติดตั้งที่ดาวน์โหลดมา อ่านข้อตกลงการใช้งาน
    แล้วเลือก I accept the terms in the License Agreement
    จากนั้นกด Next เพื่อดำเนินการต่อ
    \item ดำเนินการตามหน้าต่างติดตั้งจนถึงหน้า Ready to install Node.js
    ตรวจสอบรายละเอียด แล้วกด Install เพื่อเริ่มติดตั้ง
    รอจนติดตั้งเสร็จและปิดหน้าต่างติดตั้ง
\end{enumerate}

\subsection{การกำหนดค่า Supabase ในไฟล์ .env}
หลังจากคัดลอก Project URL และ anon key ของโครงการ Supabase แล้ว
ให้นำค่าทั้งสองไปกำหนดในไฟล์ .env ของโครงการ Pacegasus ดังนี้
\begin{enumerate}[label=\arabic*)]
    \item เปิดโฟลเดอร์โครงการใน Visual Studio Code แล้วเปิดไฟล์ .env
    ที่ใช้กำหนดค่าการเชื่อมต่อของระบบ
    \item นำ Project URL ที่คัดลอกไว้ใส่หลังเครื่องหมายเท่ากับของตัวแปร
    \texttt{SUPABASE\_URL}
    \item นำ anon key จากโครงการ Supabase เดียวกันใส่หลังเครื่องหมายเท่ากับของตัวแปร
    \texttt{SUPABASE\_ANON\_KEY}
    \item ตรวจสอบว่าค่าทั้งสองครบถ้วน แล้วบันทึกไฟล์ .env
    ก่อนเริ่มหรือเริ่มระบบใหม่เพื่อโหลดค่าการเชื่อมต่อ
\end{enumerate}
